## 🧪 Лабораторная работа №4: Нагрузочное и стресс-тестирование 

## 📌 Содержание лабораторной работы

1. **Нагрузочное тестирование (Load Testing):** Тестирование трех различных аппаратных конфигураций веб-приложения для определения оптимального соотношения цены и производительности при заданной нагрузке.
2. **Стресс-тестирование (Stress Testing):** Определение пределов выносливости выбранной конфигурации при резком увеличении числа параллельных пользователей с построением графиков зависимости времени отклика от нагрузки.
3. **Особенности окружения:** Тестируемое веб-приложение доступно во внутренней сети кафедры, доступ к серверам реализован через SSH-туннелирование.
