# 🧪 Лабораторная работа №2: Интеграционное тестирование

## 📌 Содержание лабораторной работы

1. **Разработка системы функций:**
   * При $x \le 0$: 
     $$y = \left(\frac{\left(\frac{\sec^2(x)}{\sin(x) \cdot \cos(x)}\right) - \tan(x)}{\csc(x) + (\cot(x) \cdot \csc(x))}\right)^2$$
   * При $x > 0$: 
     $$y = \left(\left(\frac{\left(\frac{\log_{10}(x) \cdot \log_3(x) + \log_3(x)}{\ln(x) + \log_{10}(x)}\right)}{\log_2(x)}\right) - \left(\frac{\log_5(x)}{\log_2(x)} - (\ln(x) - \log_{10}(x))\right)\right)$$
2. **Правила реализации:**
   * Все тригонометрические и логарифмические функции выражены через базовые (базовая тригонометрическая функция и натуральный логарифм $\ln(x)$.
   * Базовые функции реализованы через разложение в степенной ряд (ряд Тейлора) с заданной погрешностью без использования запрещенных упрощающих преобразований.
   * Для каждого модуля созданы табличные заглушки с учетом области допустимых значений (ОДЗ) и взаимозависимых точек.
   * Реализован вывод значений модулей в CSV-файл с возможностью произвольного изменения шага наращивания $X$.
3. **Интеграционное тестирование:** Анализ эквивалентности, разработка тестового покрытия с использованием **JUnit 4** и поэтапная интеграция модулей.

## 🛠 Архитектура и модули системы

* **Тригонометрический блок:** включает в себя модули `sec(x)`, `csc(x)`, `tan(x)`, `cot(x)`, `sin(x)` и базовый `cos(x)`.
* **Логарифмический блок:** включает реализации $\ln(x)$ (базовый) и производные логарифмы с разными основаниями ($\log_2, \log_3, \log_5, \log_{10}$).
* **Интеграционный модуль:** объединяет функции для вычислений на интервале $x \le 0$ и $x > 0$ с проверкой корректности комплексного взаимодействия компонентов.
