# 🧪 Лабораторная работа №1: Модульное тестирование

## 📌 Содержание лабораторной работы

1. **Модульное тестирование математической функции $\sec(x)$:** Разложение функции в степенной ряд (через ряд Тейлора для $\cos(x)$) с проверкой на достаточном тестовом покрытии.
2. **Модульное тестирование алгоритма (Heap Sort):** Тестирование алгоритма пирамидальной сортировки, проверка характерных точек внутри алгоритма и обработка различных типов входных данных.
3. **Доменное моделирование:** Формирование доменной модели по заданному текстовому описанию и разработка тестового покрытия.

## 🛠 Реализованные задачи и компоненты

### 1. Вычисление и тестирование функции $\sec(x)$
* **Суть задания:** Реализация вычисления секанса через разложение косинуса в ряд Тейлора:
  $$\frac{1}{\cos x} = \sec x, \quad \cos x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!}$$
* **Тестирование (`SecTest`):** Используются параметризированные тесты (`@ParameterizedTest`) для проверки особых точек, значений кратных $\pi$, а также граничных условий с помощью `JUnit 5` и `assertAll`.

### 2. Пирамидальная сортировка (Heap Sort)
* **Суть задания:** Программный модуль для работы с кучей и сортировки массивов данных.
* **Тестирование (`HeapSortTest`):** 
  * Проверка сортировки положительных, отрицательных чисел и нулей.
  * Проверка краевых случаев: пустой массив и обработка исключения `NullPointerException` при передаче `null`.

### 3. Доменная модель
* Разработка концептуальной доменной модели по заданному литературному отрывку (эпизод из книги «Автостопом по галактике») и проектирование для неё набора тестовых сценариев.
