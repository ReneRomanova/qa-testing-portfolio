## 🛠 Реализованные задачи и компоненты

### 1. Вычисление и тестирование функции $\sec(x)$
* **Суть задания:** Реализация вычисления секанса через разложение косинуса в ряд Тейлора:
  $$\frac{1}{\cos x} = \sec x, \quad \cos x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!}$$
* **Тестирование (`SecTest`):** Используются параметризированные тесты (`@ParameterizedTest`) для проверки особых точек, значений кратных $\pi$, а также граничных условий с помощью `JUnit 5` и `assertAll`[cite: 4].

### 2. Пирамидальная сортировка (Heap Sort)
* **Суть задания:** Программный модуль для работы с кучей и сортировки массивов данных[cite: 3, 5].
* **Тестирование (`HeapSortTest`):** 
  * Проверка сортировки положительных, отрицательных чисел и нулей[cite: 5, 6].
  * Проверка краевых случаев: пустой массив и обработка исключения `NullPointerException` при передаче `null`[cite: 5, 6].

### 3. Доменная модель
* Разработка концептуальной доменной модели по заданному литературному отрывку (эпизод из книги «Автостопом по галактике») и проектирование для неё набора тестовых сценариев[cite: 3].
