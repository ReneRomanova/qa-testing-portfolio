## 🧪 Лабораторная работа №3: Автоматизированное UI-тестирование

## 📌 Содержание лабораторной работы

1. **Формирование тестового покрытия:** На основе UseCase-диаграммы прецедентов использования веб-приложения.
2. **Разработка автотестов:** 
   * Создание шаблонов тестов с помощью **Selenium IDE**.
   * Экспорт и запуск тестов через **Selenium WebDriver / RC** в браузерах **Firefox** и **Chrome**.
3. **Особенности реализации:** Использование XPath и локаторов для поиска динамически генерируемых элементов на странице, а также настройка Maven-профилей для кроссбраузерного тестирования.

## 📋 Сценарии тестирования

В рамках лабораторной работы было реализовано и проверено 8 основных пользовательских сценариев:
1. **Регистрация (пустые поля):** Попытка зарегистрироваться без ввода логина и пароля $\rightarrow$ получение сообщения об ошибке.
2. **Регистрация (некорректный пароль):** Ввод недопустимого пароля $\rightarrow$ проверка появления валидационной ошибки.
3. **Авторизация (успешная):** Ввод корректного логина и пароля $\rightarrow$ успешный вход на главный экран приложения.
4. **Добавление проекта:** Авторизация $\rightarrow$ переход в раздел «Трафиковое продвижение» $\rightarrow$ попытка добавить проект без указания имени/адреса $\rightarrow$ получение ошибки.
5. **Проверка тарифов:** Авторизация $\rightarrow$ переход в «Инструменты» $\rightarrow$ «Тарифы» $\rightarrow$ проверка корректности отображения текстовых блоков и описания биллинга.
6. **Раздел помощи (FAQ):** Авторизация $\rightarrow$ переход в сообщения / техподдержку $\rightarrow$ «Часто задаваемые вопросы» $\rightarrow$ выбор вопроса и сверка контактов/почты поддержки.
7. **Проверка отчетов:** Авторизация $\rightarrow$ переход в раздел «Отчеты» $\rightarrow$ проверка корректности данных и элементов интерфейса.
8. **Проверка фильтров:** Авторизация $\rightarrow$ «Инструменты» $\rightarrow$ «Фильтры» $\rightarrow$ применение параметров и сравнение результатов работы фильтрации.
