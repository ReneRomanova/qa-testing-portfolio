# 🧪 Лабораторные работы по курсу «Тестирование программного обеспечения»

📍 **Университет:** ИТМО  
📍 **Факультет:** Программной инженерии и компьютерных технологий (ФПИиКТ)

---

## 📌 Содержание

| № | Тема лабораторной работы | Основной инструмент / Технология |
| :---: | :--- | :--- |
| **1** | [Модульное тестирование (Unit Testing)](#лабораторная-работа-1) | JUnit / Mockito / TestNG |
| **2** | [Интеграционное тестирование (Integration Testing)](#лабораторная-работа-2) | Testcontainers / Spring Boot Test / БД |
| **3** | [Автоматизированное UI-тестирование](#лабораторная-работа-3) | Selenium / Selenide |
| **4** | [Нагрузочное и стресс-тестирование](#лабораторная-работа-4) | Apache JMeter |

---

### 🔹 Лабораторная работа №1: Модульное тестирование (Unit Testing)
* Написание юнит-тестов для проверки изолированных модулей приложения.
* Использование моков, стабов и проверка покрытия кода тестами (Code Coverage).

### 🔹 Лабораторная работа №2: Интеграционное тестирование (Integration Testing)
* Проверка взаимодействия нескольких компонентов системы (например, сервисов с реляционными базами данных).
* Настройка окружения и поднятие изолированных зависимостей.

### 🔹 Лабораторная работа №3: Автоматизированное UI-тестирование (Selenium)
* Автоматизация пользовательских сценариев взаимодействия с веб-интерфейсом.
* Реализация паттерна Page Object Model (POM) для поддержки стабильности тестов.

### 🔹 Лабораторная работа №4: Нагрузочное и стресс-тестирование (JMeter)
* Моделирование пользовательской нагрузки на веб-приложение или API.
* Сбор метрик производительности (throughput, response time, error rate) и анализ результатов.
